# 🎨 ريشة - متجر اللوحات الفنية

موقع e-commerce متخصص في بيع اللوحات الفنية الأصلية بتصميم عصري وسهل الاستخدام.

## 🌟 المميزات

✅ **تصميم RTL احترافي** - دعم كامل للعربية  
✅ **عرض المنتجات** - شبكة ديناميكية للمنتجات  
✅ **سلة التسوق** - إدارة المنتجات المختارة  
✅ **قائمة المفضلة** - حفظ المنتجات المفضلة  
✅ **فئات المنتجات** - تصنيف منظم للمنتجات  
✅ **طلب مخصص** - خاصية طلب لوحات حسب المواصفات  
✅ **متجاوب** - يعمل على جميع الأجهزة  
✅ **تصميم عصري** - واجهة مستخدم جميلة وبسيطة

## 🚀 البدء السريع

### 1. استنساخ المشروع
```bash
git clone https://github.com/yourusername/riysha-art-gallery.git
cd riysha-art-gallery
```

### 2. فتح الموقع
ببساطة افتح ملف `index.html` في متصفحك أو استخدم خادم محلي:

```bash
# استخدام Python 3
python -m http.server 8000

# أو استخدام Node.js (Live Server)
npx live-server
```

ثم زر: `http://localhost:8000`

## 🛠️ التطوير والتخصيص

### تغيير الألوان الأساسية
عدّل متغيرات CSS في `css/style.css`:

```css
:root {
    --primary-color: #8B6F47;
    --secondary-color: #2c2c2c;
    --accent-color: #D4AF37;
}
```

### إضافة منتجات جديدة
عدّل قائمة المنتجات في `js/script.js`:

```javascript
const products = [
    { name: 'اسم اللوحة', price: 1200, dimensions: '80 × 60 سم' },
    // أضف منتجات إضافية هنا
];
```

### تخصيص النصوص
كل النصوص موجودة في `index.html` ويمكنك تعديلها مباشرة.
